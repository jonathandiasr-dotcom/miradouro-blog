Minimal square (or round) picto-only button — the "bouton minimaliste" of charte p.16, used for mobile nav and carousels.

```jsx
<IconButton icon="chevron-left" variant="blue" label="Précédent" />
<IconButton icon="house" variant="gold" label="Accueil" />
```

Alternate blue and gold in a row. Round form only for pictogram cartouches, never for chevrons.
