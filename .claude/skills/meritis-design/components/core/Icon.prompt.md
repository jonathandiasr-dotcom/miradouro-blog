A single-colour line pictogram, masked from the Lucide CDN so it always takes the surrounding text colour.

```jsx
<Icon name="arrow-right" size={20} />
<Icon name="database" size={48} color="var(--mrt-gold)" />
```

Only bleu marine or doré on light grounds; gris clair or beige on dark grounds (charte p.12). Substitute for the brand's Noun Project set — see readme.md ICONOGRAPHY.
