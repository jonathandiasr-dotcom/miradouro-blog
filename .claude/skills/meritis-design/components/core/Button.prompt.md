The brand CTA — square-ish (4px radius), bold Aptos label, one accent colour at a time.

```jsx
<Button variant="primary">Parlons de votre projet</Button>
<Button variant="gold" icon="send">Envoyer</Button>
<Button variant="on-dark">Nous rejoindre</Button>
```

On a light ground use `primary`, `gold`, `outline` or `outline-gold`; on bleu marine / doré grounds only `on-dark`. Hover fills or deepens; press shrinks 1.5%. Never two solid CTAs of the same colour side by side — pair primary + gold, or solid + outline.
